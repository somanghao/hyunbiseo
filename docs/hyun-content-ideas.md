# 현비서 상황별 콘텐츠 추천 — 새 아이디어 (2026-11-09)

댄 요청(#봇-작업): "상황별로 보여주면 좋을 내용들 추천해줘". 코드는 바꾸지 않고 다음 구현 후보만 정리한다.
이미 들어간 것은 [[hyun-content-plan]] 과 docs/hyun-app.md 에 있다. 여기 적은 것은 그것과 겹치지 않는 **새 아이디어**다.
- 이미 들어간 것: 시동 화면(차 컨디션·날씨·첫 일정·장·관심 뉴스·온기 퀘스트), 출발 준비(목적지·도착 시각), 주행(내비·차 상태 6초 알림), 신호대기(동네 이야기), 주차(주행 요약·포인트·웹툰), 시동 끔(하루 정리·내리기 전에·내일·꾸미기), 차 신호 반응(비·동승자·뒷좌석·온도·배터리·크루즈·벨트·전조등·10km).

기준(댄 방향)
- 어시스턴트 먼저, 말 위주.
- 운전 중엔 한눈(초점 하나)만 보이고 터치는 없다.
- 앱은 차 안 인테리어 소품처럼 둔다.
- 안전운전 → 온기 포인트 → 꾸미기 고리를 돌린다.
- 초보 팁을 챙기고, 말투는 장난스럽게.

표기
- **출처**: ✅ = 지금 바로 읽을 수 있음, 🟡 = 연동이나 키가 필요함, ❌ = 막혀 있음.
  - Pleos 서드파티 신호 중 되는 것: 조향각·브레이크·크루즈·트립 시간/거리·방향지시등·좌석/벨트·문·창·와이퍼·전조등·공조·배터리.
  - Pleos 에서 안 되는 것: 속도·가속페달·차선·타이어·운전자 카메라. 속도와 기어는 AAOS 로 읽는다.
- **시선**: 음성(말로만) · 한눈(1초) · 훑기(카드 2~4장) · 풍부(목록·그림).
- **작업 크기**: S = 하루 안팎, M = 2~4일, L = 1주 이상 또는 외부 연동.

참고한 것(간단 조사)
- **Mercedes MBUX "Zero Layer"**: 상황에 맞는 기능을 첫 화면에 올리고, "화요일 저녁 통화"처럼 반복되는 습관을 운전자 프로필별로 먼저 제안한다.
- **NIO NOMI**: 개인화 인사·날씨, 생활 리듬을 익혀 경로와 일정을 제안한다.
- **Tesla**: 세차 모드(창·와이퍼·잠금 한 번에), 캠프 모드, Toybox(로맨스 모드 벽난로·포토부스)처럼 "차가 놀이 공간"이 되는 기능들.
- **Pleos/Gleo AI**: 차량 제어·길 안내·검색이 중심이고, 개인화 서비스는 앞으로 내놓을 계획이다.
- **티맵**: 운전점수(과속·급가감속·급정거) → 보험 할인·포인트로 이어 주는 보상 고리.

## 앱에 넣은 상태(11-09, 댄 "각 항목들 레이아웃 구성하고 예제 추가해줘")
37개(상황별 30 + 특별한 순간 7)를 모두 앱 화면으로 만들었다. 실제 데이터가 있으면 실제 값, 없으면 예시 값을 쓰고 화면에 "예시"라고 표시했다.

**보는 법**
- 허브 주행 상태 패널 **'아이디어' select**(끄기 = 자동 흐름)
- `adb shell am broadcast -a io.github.somanghao.makecar.hyun.SIM --es idea <id>` — `--es moment <id>` 도 같다. 끄기는 `--es screen auto`
- 앱 디버그 판(상황 글자 세 번 누르기) **'상황별 아이디어'** 줄의 이전 / 다음 / 끄기

**어디에 뜨나**
- 시동·주차·시동 끔: 상황 화면 맨 위 카드로 뜬다.
- 출발 준비·신호대기: 초점 카드 하나만 남기고 나머지는 숨긴다(버튼 없음).
- 주행: 내비 오른쪽 위 칸 한 줄 + 캐릭터의 말.
- 강제 전환 뒤에 실제 VHAL 주행 신호가 와도 아이디어는 남는다.
- 기본·내쉬 스킨 둘 다 적용된다. 주행 중엔 터치가 없다.

**특별 효과**: `rain` 은 비 장면(우산·빗줄기), `night` 는 밤 화면(nightOverride)을 함께 켠다.

**id · 데이터**(✅ 실제 / 예시)

| 신호대기 | `quiz` 동네 퀴즈(예시) · `score` 경기 점수(예시) · `signal` 신호 길이(예시) · `stretch` 스트레칭(트립 시간 ✅) |
