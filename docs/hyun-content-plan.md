# 현비서 콘텐츠 기획 — 상태별 정보 · 취미 정보 레이아웃 (2026-11-09)

댄 요청(#봇-작업): "차량 상태(시동 → 운전 중 → 정차 …)마다 보여 주면 좋을 정보를 정리하고, 뉴스 · 내비 · 웹툰 같은 취미 정보는 정보마다 레이아웃이 다르게."
앱 코드는 아직 안 바꿨다 — 이 문서는 다음 구현의 기준. 디자인 원칙은 [[hyun-design]](스펙 · unslop) 그대로: 캐릭터는 화면 높이 약 33%, 메시지는 카드 한 장 중심, 주행 중엔 요소 둘 · 글자 24px 이상 · 움직임 없음.

목업(코드로 그린 HTML → 헤드리스 크롬, 앱 영역 비율 1280×1000, Pretendard · 실제 캐릭터 그림 · 실제 데이터):

## 0. 읽을 수 있는 데이터(근거)

| 출처 | 항목 | 비고 |
|---|---|---|
| Pleos Vehicle SDK | 조향각 · 브레이크 페달 · 크루즈 상태/목표 속도 · 주행 모드 · 트립 시간/거리 · 누적 거리 · 주행 가능 거리 · 방향지시등 · 착석/벨트 · 문 · 창 · 와이퍼 · 전조등 · 공조 온도 · 배터리/연료 · 차량 정보(VIN) | 서드파티 차단: 타이어 공기압 · 텔테일(경고등) |

| 외부 | 날씨(Open-Meteo) · 뉴스(연합뉴스 RSS, 사진 포함) · 웹툰(네이버 인기, 표지) · 주식(네이버 증권) · 영화 · 일정(폰 짭비서/서버 할 일) · 주변 장소(카카오 로컬 — 서버 도착 추천만 연결) | 스포츠 점수 · 음악 재생 정보는 연동 전(목업은 예시) |
| 운전자 정보 | 초보/숙련 · 관심사(서버 taste) · 이름 | 초보는 팁·부드러운 감점 |

공통 규칙
- 캐릭터는 늘 왼쪽(높이 33%) — 카테고리가 바뀌어도 캐릭터 캡션 한 줄이 그 정보를 말로 요약("오늘 장은 조금 내렸어요").
- 카테고리 레이아웃은 색만 바꾸지 않는다 — 정보의 모양이 다르다(사진 / 큰 화살표 / 표지 / 정사각 / 전광판 / 큰 숫자 + 선 / 큰 기온 / 인용 / 시간 축).
- 주행 중엔 내비 레이아웃만, 나머지는 음성. 신호대기는 "한 줄" 버전, 주차는 "전체" 버전.
- 숫자는 고정폭, 등락 색은 의미에만(상승 빨강 · 하락 파랑 — 국내 관례), 강조색은 화면당 1~2곳.
- 예시 데이터(스포츠 · 동네 이야기 · 음악 · 일정)는 연동 전까지 "예시" 표시.

## 3. 다음 구현 순서(제안)
1. 카테고리 레이아웃 컴포넌트 9종을 StageUi 에 추가하고 `Tile` 에 레이아웃 종류를 붙인다
2. 상태 × 카테고리 허용표(위 표)를 코드 상수로 — 주행 중엔 자동으로 음성 전용
3. 연동: 스포츠(공식 API 검토) · 미디어 세션(지금 재생) · 카카오 로컬 일반 검색(서버) · 일정
4. 관심사(taste)로 카테고리 순서 정하기 — 시동 화면 관심 소식 1건의 종류를 사용자마다 다르게
