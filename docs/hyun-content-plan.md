# 현비서 콘텐츠 기획 — 상태별 정보 · 취미 정보 레이아웃 (2026-11-09)

댄 요청(#봇-작업): "차량 상태(시동 → 운전 중 → 정차 …)마다 보여 주면 좋을 정보를 정리하고, 뉴스 · 내비 · 웹툰 같은 취미 정보는 정보마다 레이아웃이 다르게."
앱 코드는 아직 안 바꿨다 — 이 문서는 다음 구현의 기준. 디자인 원칙은 [[hyun-design]](스펙 · unslop) 그대로: 캐릭터는 화면 높이 약 33%, 메시지는 카드 한 장 중심, 주행 중엔 요소 둘 · 글자 24px 이상 · 움직임 없음.

목업(코드로 그린 HTML → 헤드리스 크롬, 앱 영역 비율 1280×1000, Pretendard · 실제 캐릭터 그림 · 실제 데이터):
- 상태별 6장 — `docs/img/content-plan-states.png`
- 취미 카테고리 9장 — `docs/img/content-plan-categories.png`

## 0. 읽을 수 있는 데이터(근거)

공통 규칙
- 캐릭터는 늘 왼쪽(높이 33%) — 카테고리가 바뀌어도 캐릭터 캡션 한 줄이 그 정보를 말로 요약("오늘 장은 조금 내렸어요").
- 카테고리 레이아웃은 색만 바꾸지 않는다 — 정보의 모양이 다르다(사진 / 큰 화살표 / 표지 / 정사각 / 전광판 / 큰 숫자 + 선 / 큰 기온 / 인용 / 시간 축).
- 주행 중엔 내비 레이아웃만, 나머지는 음성. 신호대기는 "한 줄" 버전, 주차는 "전체" 버전.
- 숫자는 고정폭, 등락 색은 의미에만(상승 빨강 · 하락 파랑 — 국내 관례), 강조색은 화면당 1~2곳.
- 예시 데이터(스포츠 · 동네 이야기 · 음악 · 일정)는 연동 전까지 "예시" 표시.

## 3. 앱 반영(11-09, 댄 "우선 추가 · 각 화면 볼 수 있게 · 내비는 상시")
- 상황 화면 6 · 취미 레이아웃 9 를 앱에 넣었다(`StageUi.stateScreen()` · `category()`). 실제 에뮬 캡처 = `docs/img/content-app-states.png` · `docs/img/content-app-categories.png` · `docs/img/content-app-nav.png`
- 실제 데이터: 뉴스(연합뉴스 RSS 제목·사진·시각) · 날씨(Open-Meteo 현재·시간대·최저/최고·내일) · 웹툰(서버 네이버 웹툰 인기·표지·별점) · 주식(서버 네이버 증권 지수·시총 상위) · 차 컨디션(Pleos → AAOS → 모의) · 주행 기록·포인트(앱)
- **예시 데이터(연동 전, 화면에 "예시" 표시)**: 음악 지금 재생·대기열(미디어 세션 연동 전) · 스포츠 점수·이닝(스포츠 API 검토 중) · 동네 이야기·근처(카카오 로컬 일반 검색 서버 연동 전) · 일정·가는 김에(폰 일정·할 일 연동 전) · 웹툰 "128화" 이어보기 · 주식 장중 선 모양 · 출발 준비 추천 목적지 거리/시간(내비 목적지가 없을 때)
- 상시 내비 띠: 경로 안내 중이면 모든 레이아웃 위에(폰의 진행 중 내비 알림처럼). 누르면 내비 주화면. 경로 소스 = NaviHelper 목적지, 없으면 모의 경로(`SIM --es nav on`)
- 내비 주화면(댄 11-09 "내비가 주화면일 때는 캐릭터를 좌측 상단으로 줄이고 내비 영역을 넓게"): 캐릭터 배지 14% · 큰 회전/차로/도착 + 경로 지도, 전환 0.48초
- 화면 보기: 허브 주행 상태 패널 '화면' select + '내비' 칩 · `adb shell am broadcast -a io.github.somanghao.makecar.hyun.SIM --es screen <키> --es nav on|off`(`auto` = 자동으로) · 앱 왼쪽 위 상황 글자 세 번 = 디버그 판
- 허용 규칙(위 표)은 자동 흐름에 적용 — 주행 중엔 내비만, 미리보기만 예외("미리보기" 칩)

### 운전 중 한눈 규칙(11-09, 댄 "주행 중 레이아웃은 한눈에, 복잡하지 않게")
대상 = 출발 준비(D) · 주행 중 · 신호대기 · 상시 내비 띠 · 운전 중 내비 화면. (시동 · 주차 · 시동 끔은 풍부해도 됨)
- 화면당 초점 하나 + 보조 1~2개. 한 번 볼 때 2초 안(NHTSA 시각-수동 주의 지침: 한 번 2초 · 합계 12초), 스크롤 없음
- 큰 글자(본문 34px 이상, 핵심 숫자 110~190px) · 높은 대비. 작은 라벨 · 여러 칸 격자 · 차트 · 썸네일 · 목록 · 꾸밈 없음 · 독 숨김 · 신호 반응 이야기 줄 숨김
- 내비(운전 중): 큰 회전 화살표 + 거리 + 회전 종류 + 길 이름 / 차로 한 줄 / 도착 시각 + 남은 분. 지도 없음. "그다음"은 200m 안에 이어질 때만 한 줄. 차 상태 알림은 차로 자리에 6초
- 상시 내비 띠: 화살표 · 거리 · 길 이름 · 도착 시각만
- 출발 준비(D): 목적지 · 도착 시각/분 · 큰 버튼 하나(안내 시작 / 내비 크게 보기) + 보조 한 줄(배터리 30% 미만 경고, 없으면 초보 팁)
