## 1. 목적 · 심사 4축

시동을 걸면 **내 관심사**(응원하는 야구팀·경제·IT·우리 동네)로 고른 **어제 있었던 일 + 오늘 아침 소식**을 남은 운전 시간에 맞춰 읽어 준다.

- 차량특화성: 남은 운전 시간(내비)에 맞춘 분량 · 회전 앞·내비 안내 때 멈춤 · 시동 = 하루의 시작 시점
- 창의성: 라디오처럼 모두 같은 뉴스가 아니라 대화로 쌓인 취향이 고른 '나만의 아침 뉴스'
- 기술활용성: NaviHelper `onDrivingInfo` 남은 시간 · 서버 정보 통로(분야별 RSS) · 취향 기록 · 두뇌 요약(출처 표기) · 말하기 스케줄러
- 사업성: 뉴스·라디오 제휴(분야별 전문) · 관심사 맞춤 광고 없는 구독 · 출근길 콘텐츠

## 2. 11-15 MVP 시연 장면

1. (전에 나눈 대화 · 취향 질문 '어떤 소식을 먼저 들으면 좋을까요?'로 취향에 '야구 = LG' · '경제' 기록됨 — 관심 분야를 따로 묻는 화면은 없음)
2. 하루 첫 시동 → "좋은 아침이에요. 오늘 브리핑은 날씨, LG 소식, 경제 순으로 할게요. 강남역까지 46분이라 세 꼭지예요." (순서 = 사용자가 정한 `brief_order` — 여기선 날씨를 먼저 듣겠다고 한 경우)
3. 날씨 한 줄 → "어제 LG는 ○○에 5대 3으로 이겼어요(출처 연합뉴스)" → "경제: 코스피가 …(출처)"
4. 오른쪽 정보창(정차) 또는 한 줄(주행)에 "브리핑 2/3 · LG 트윈스"
5. "다음" · "그만" · "그거 더 자세히" → 검색 모드로 기사 한 편 요약
6. 정차 → "오늘 들은 것" 카드(제목 3 · 출처 · 시각)

## 3. 언제 켜지나

| 트리거 | 조건 |
|---|---|
| 하루 첫 시동 | 그날 처음 앱 켬 · 정차 → 순서(저장된 `brief_order` — 날씨도 그 순서 안에서) · 개인화 꼭지 · **자동은 하루 한 번만** |
| 분량 | 남은 주행 **15분 미만 = 1꼭지 · 15~40분 = 2꼭지 · 40분 넘음 = 3꼭지** (목적지가 없으면 2꼭지) |
| "브리핑 해 줘" | 언제든(이미 있음) — 두 번째 시동부터는 이 말로만 |
| 멈춤·다음 | "다음" · "그만" · 회전 300m 안 · 내비 음성 · P0 |
| 관심사 쌓기 | 대화 중 자동(이미 있는 취향 칸) + 기존 취향 질문(`news` 칸 "어떤 소식을 먼저 들으면 좋을까요?") 한 번 + "경제 뉴스도 넣어 줘" |

## 6. 앱 기능 — `feature/BriefFeature.kt` (작음)

- 시동 순서·꼭지 고르기는 서버가 하고, 앱은 진행 표시만: `render` = 주행 한 줄 "브리핑 2/3 · 경제" / 정차 '오늘 들은 것' 카드
- `onHeard`: "다음"·"그만"·"다시"(앱이 바로) · `onReply`: 두뇌 답 `brief: {i, n, title, source}`

## 7. 서버 기능 모듈 — `server/hyun/features/briefing.py`(있음) 확장 + `feeds.py`

- `feeds.py`: 분야별 연합뉴스 RSS 추가(경제 `economy.xml` · 스포츠 `sports.xml` · 산업·IT `industry.xml` · 필요하면 지역 `local.xml`) — `fetch_<cat>` + 표 한 줄씩(정보 통로 확장 지점) · 실서비스 출처 확대는 제휴 API(기획서 '제휴 시')
- `briefing.py`: 개인화 고르기 = 취향 칸(야구팀·`news` 칸 관심 분야) × 분야별 헤드라인 → 꼭지 1~3(남은 시간: 15분 미만 1 · 15~40분 2 · 40분 넘음 3) · 하루 첫 시동에만 자동(그날 했는지 기록) · '어제' 결과(스포츠 = 검색 모드) · 순서는 `brief_order`
- `RULES`: 제목 + 한 줄 요약 + 출처 · 지어내기 금지 · 꼭지 사이 짧게
- `SCHEMA`: 기존 `brief_order` + `brief: {i, n, title, source}`(진행 표시)
- `block`: `[브리핑]` 오늘 꼭지 목록 · 남은 시간

## 8. 주행 규칙

- 주행 중: 소리 + 한 줄 진행 표시만 · 기사 글·목록 없음 · 회전 앞 멈춤
- 정차: '오늘 들은 것' 카드(제목·출처·시각) · 누르면 다시 듣기

## 10. 결정 (11-08 · Claude 권고 — 사용자 위임, 바꿀 수 있음)

| 질문 | 결정 | 이유 |
|---|---|---|
| 관심 분야 등록 | 따로 묻지 않고 **기존 취향 질문(`news` 칸)으로 한 번** + 대화 중 자동 | 질문이 늘면 잔소리 — 이미 있는 취향 질문 흐름을 쓴다 |
| 뉴스 출처 | **연합뉴스 RSS 분야별**(종합 · 경제 · 스포츠 · 산업·IT) — 주소 응답만 확인(미시험) · 방송사·제휴는 기획서 '제휴 시' | 한 출처라 표기·형식이 같고, 키가 필요 없다 |
| 분량 | 남은 주행 **15분 미만 1꼭지 · 15~40분 2꼭지 · 40분 넘음 3꼭지** | 도착 전에 끝나는 길이 |
| 자동 브리핑 | **하루 첫 시동만** · 이후엔 "브리핑 해 줘" | 시동마다 하면 짧은 이동이 시끄럽다 |
| 날씨 위치 | 사용자가 정한 **`brief_order` 순서를 따른다**(고정 첫 꼭지 아님) | 코어 ③에서 사용자가 순서를 직접 정했다 |
