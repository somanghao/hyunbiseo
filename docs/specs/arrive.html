도착 추천 arrive — 화면 구성도구현 · E2E 2/2 (11-08)

식사 시간에 도착하는 길이면 1km 전에 한마디 하고, 세우면 목적지 근처 취향 맞춤 식당 카드 · 고르면 그곳으로 안내(카카오 로컬)

짝 문서: 기능 명세 arrive.md

회색 점선 = 지금 있는 요소 · 색 테두리 + 번호 = 이 모듈이 새로 넣는 요소(같은 번호 = 같은 요소) · 실제 비율(1칸 1706×1210 · 반반 841×1210 앱 영역, 화면엔 36%로 줄임) · 오른쪽 정보창의 새 판은 '그리기 훅'(예정) 자리

번호별 설명

  1. 곧 도착 한 줄(주행) — 1km 앞에서 말 한 문장 + 글자 한 줄 '도착 12:10 점심 · 국밥 3곳 찾아 둠'(이름 목록 없음)
  2. 도착 추천 카드(정차) — 목적지 근처 5곳: 번호 · 이름 · 목적지에서 m · 종류 · 왜(취향) · 출처 '카카오 로컬 · 실시간' · 누르면 닫힘
  3. 말로 고르기 안내 — '두 번째로 안내해 줘'(그 식당으로 경로) · '다른 데' · '카페는?'

주행 규칙

주행 중엔 말 한 문장 + 글자 한 줄(장소 이름 목록 없음) · 카드는 숨김. 정차하면 카드 5곳 · 고르기는 말로(터치도). 식사 시간이 아니거나 목적지가 식당·카페면 먼저 말하지 않음.
