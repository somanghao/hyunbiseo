## 1. 목적 · 심사 4축

초보 운전자가 어려워하는 순간(고속도로 합류·좌회전·터널·요금소·회전교차로·사고)이 **오기 직전에** 그림 한 장 + 한 문장으로 알려 준다. 정차하면 같은 팁을 큰 그림으로 다시 보여 준다.

- 차량특화성: 내비 다음 안내 종류(TurnType 43종)·거리·속도·날씨로 '지금 이 길'에 맞는 팁 — 폰 앱은 이 타이밍을 못 안다
- 창의성: 화면 누르는 온보딩이 아니라 달리는 동안의 조수석 코치 · 같은 팁을 주행 중엔 한눈 그림, 정차 땐 자세한 그림으로
- 기술활용성: NaviHelper TBT(종류·방면·거리) · AAOS 속도 · 경로 정찰(사고 → 대처 팁) · 말하기 스케줄러(회전 300m 앞 침묵과 맞물림)
- 사업성: 신규 운전자·렌터카·카셰어링 '처음 타는 차' 안전 교육 · 보험·운전학원 제휴(확장)

## 2. 11-15 MVP 시연 장면

1. (처음 켤 때 한 번) "운전 몇 년 하셨어요?" → "이제 반년이요" → 1년 미만이라 초보 모드 — 또는 "현비서야 초보 모드로 해 줘" → "초보 모드 켰어요. 어려운 길이 오면 미리 알려 드릴게요. '그만'이면 꺼요."
2. 강남역 경로 주행(에뮬 경로에 실제로 `TURN_ENTER_IC_C` 대왕판교IC · `TURN_TOLL` 대왕판교톨게이트가 있다)
3. 고속도로 진입 800m 앞 → **주행 중 그림 카드 6초**(1칸 = 내비 판 바로 아래 · 진입 픽토그램 + "깜빡이 먼저") + 음성 "곧 고속도로 진입이에요. 깜빡이 켜고 속도 맞춰요."(P2)
4. 회전 300m 안 → 침묵(기존 회전 앞 침묵)
5. 요금소 앞 → "하이패스 없으면 오른쪽 일반 차로예요" 그림 카드
6. 정차 → 오른쪽 정보창에 **오늘 본 팁** 큰 그림(진입 차로 그림 · 3줄 설명) · "다음 팁"·"그만" 칩

## 3. 언제 켜지나

| 트리거 | 조건 | 팁(예) |
|---|---|---|
| 고속도로 진입 | TBT `TURN_ENTER_IC_*`가 300~1000m 앞 | 깜빡이 먼저 · 가속 차로에서 속도 맞춰 합류 |
| 고속도로 나가기 | `TURN_EXIT_IC_*` | 미리 오른쪽 차로 · 감속 차로에서 줄이기 |
| 좌회전·유턴 | `TURN_LEFT`·`TURN_UTURN` 300~800m | 1차로 미리 · 신호·보행자 확인 |
| 합류 | `TURN_DEVIDE_MERGE` | 옆 차 속도 보고 끼어들기 |
| 터널 | `TURN_TUNNEL` | 전조등 켜기 · 차로 바꾸지 않기 |
| 요금소 | `TURN_TOLL` | 하이패스 차로 구분 |
| 회전교차로 | `TURN_ENTER_ROUNDABOUT_*` | 안에 있는 차가 먼저 · 나갈 때 깜빡이 |
| 사고 앞 | 경로 정찰 위험 P0 뒤 | 비상등 · 2차 사고 피해 가드레일 밖으로(고속도로 사고 조치) |
| 비·밤 | 날씨 비 확률·시간 | 속도 줄이기 · 안전거리 두 배 |
| 정체 끝 ★ | 경로 정찰 정체 시작 1km 앞 · 속도 70 이상 | 미리 감속 · 비상등(숙련 모드에도) |
| 처음 켤 때 | 운전 경력을 아직 모름 · 정차 중 | "운전 몇 년 하셨어요?" → 1년 미만이면 초보 모드(한 번만, 말로 언제든 바꿈) |
| 운전자 말 | "합류 어떻게 해?" · "하이패스 차로 어디야?" | 두뇌가 초보 눈높이로 · 신호가 없는 팁(비보호 좌회전·버스전용차로·내리막·긴급차량·경사로)도 여기서 |

- 팁 20개 전체·트리거·문장 → [tutor-tips.md](tutor-tips.md) · **MVP = 트리거 6개**(고속도로 진입 · 진출 · 회전교차로 · 터널 · 요금소 · 유턴 — 전부 TBT 종류)
- 같은 팁은 하루 한 번 · 회전 300m 안·내비 음성 중엔 말 안 함 · 숙련 모드면 끄되 **안전 팁(사고 대처 · 정체 끝 급정거)은 남김**

## 6. 앱 기능 — `feature/TutorFeature.kt` + `assets/tips.json`

- `tips.json`: 팁 20 = `{id, triggers[], say[], card(6자 안), pict, detail[3줄], safe(숙련 모드에도)}` — **내용 정본 = [tutor-tips.md](tutor-tips.md)**(Claude 초안 · 팀은 검토만)
- `tick`: 다음 안내 목록에서 팁 대상 찾기 · 하루 한 번 기록 · 회전 게이트 확인
- `onHeard`: "초보 모드로"·"숙련 모드로"·"팁 그만"·운전 경력 대답("반년"·"3년" → 1년 미만이면 초보)(앱이 바로) · `render`: 지금 팁(그림·짧은 글) · 정차 '오늘 본 팁'
- 처음 켤 때: 앱 설정 `driveYears`가 없으면 정차 중 한 번 묻는다(P3) — 대답 없으면 숙련(조용한 쪽)
- `ctx`: `novice: true`(두뇌가 질문에 초보 눈높이로) · `fallback`: 팁 문장은 앱이 가짐(두뇌 없어도 됨)
- 그림: **코드 픽토그램**(`pict` 이름 — 차로·화살표·표지를 선으로, `HyunView.turnIcon`과 같은 방식) · 디자인 의뢰는 11-15 뒤

## 7. 서버 기능 모듈 — `server/hyun/features/tutor.py`

- `RULES`: 초보 모드면 길·운전 질문에 '한 문장 + 할 일 하나'로, 겁주지 않게
- `SCHEMA`: `tutor_mode: "novice" | "expert" | ""`(말로 바꿀 때)
- `block`: `[운전 모드] 초보` · 오늘 이미 말한 팁
- MVP는 팁 고르기·말을 앱이 하고, 서버는 질문 답 눈높이만

## 8. 주행 규칙

- 주행 중: **한눈 그림 카드**(그림 1 + 6자 안 글) **6초** · **1칸 = 내비 판 바로 아래 · 반반 = 길 카드 아래** + 음성 한두 문장 — 터치 없음 · 우선순위 최고 하나만 · 회전 300m 안에선 새 카드·말 안 냄
- 정차: 큰 그림 + 설명 3줄 + '다음 팁'·'그만' 칩(터치) · 오늘 본 팁 다시 보기

## 9. E2E 케이스 초안

```json
{
  "id": "e12",
  "title": "튜토리얼 — 초보 모드 · 고속도로 진입 · 요금소 팁(그림 + 음성)",
  "situation": "초보 운전자 · 강남역 가는 길 · 800m 앞 대왕판교IC로 고속도로 진입",
  "why": "내비 다음 안내 종류로 어려운 길이 오기 직전에 그림 카드 + 한 문장, 정차하면 큰 그림으로 다시",
  "steps": [
    {"do": "say", "text": "초보 모드로 해 줘", "voice": true},
    {"wait": "reply", "timeout": 30},
    {"do": "intent", "extras": "--es dest 강남역 --ef lat 37.4979 --ef lng 127.0276"},
    {"wait": "log", "pattern": "navi\\|routeStarted", "timeout": 40},
    {"do": "vc", "args": ["gear", "Drive"]}, {"do": "vc", "args": ["speed", "50"]},
    {"wait": "log", "pattern": "tutor\\|tip\\|", "timeout": 30},
    {"wait": "sec", "sec": 2},
    {"shot": "주행 중 그림 카드 — 고속도로 진입 팁"},
    {"do": "vc", "args": ["speed", "0"]}, {"do": "vc", "args": ["gear", "Park"]},
    {"wait": "sec", "sec": 3},
    {"shot": "정차 — 오늘 본 팁 큰 그림"}
  ],
  "expect": [
    {"log": "tutor\\|mode\\|novice", "what": "초보 모드 켬"},
    {"log": "tutor\\|tip\\|.*ENTER_IC", "what": "진입 안내 앞에서 팁"},
    {"log": "say\\|P2\\|.*깜빡이", "what": "한 문장 음성 팁"}
  ]
}
```

- 케이스 설명 슬라이드: **상황** "초보 운전자 · 800m 앞 고속도로 진입" · **내가 할 말** "현비서야, 초보 모드로 해 줘"
