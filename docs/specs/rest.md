## 1. 목적 · 심사 4축

오래 달린 운전자에게 **쉬어 갈 때를 먼저 알려 주고, 휴게소에서 15분 쉼표를 같이 지켜 준다**(카메라가 없으니 '졸음 감지'가 아니라 '피로 예측').

- 차량특화성: 연속 주행 시간·속도·기어·경로의 다음 휴게소(TBT)를 묶어 차에서만 되는 타이밍으로 말한다
- 창의성: 알림 한 번이 아니라 '제안 → 휴게소 → 15분 타이머·숨 고르기 → 깨우기 → 남은 길 안내'로 이어지는 쉬는 시간 한 바퀴
- 기술활용성: AAOS 속도·기어 · NaviHelper TBT(`TURN_ENTER_SERVICEAREA`·`TURN_RESTAREA`) · 휴게소 소개(검색 모드·소개 카드) 재사용 · 말하기 스케줄러 P1
- 사업성: 장거리·화물·법인차 피로 관리(휴게 기록) · 휴게소 매장 제휴(취향 맞춤 메뉴 추천) 확장

## 2. 11-15 MVP 시연 장면

1. 고속도로 연속 2시간 주행(시연: 연속 주행 기준을 1분으로 줄여 주입) → 경로에 12km 앞 휴게소
2. 현비서(P1): "두 시간째 달리고 있어요. 12킬로미터 앞 기흥휴게소에서 15분 쉬어 갈까요?"
3. 운전자: "응, 쉬어 갈래" → "좋아요, 휴게소 들어가면 알려 드릴게요." (경로 위 휴게소라 경유지 추가 없음)
4. 휴게소 도착 → 기어 P → **쉼표 화면**: 15분 타이머(고정 · "5분 더"로만 늘림) · 숨 고르기 안내(음성 한 번) · 휴게소 소개 카드(대표 메뉴 · 취향 추천)
5. 12분부터 깨우기 3단계: ① "3분 남았어요" ② "가볍게 기지개 켜 볼까요" ③ "출발 준비됐어요? 강남역까지 1시간 10분 남았어요"
6. 기어 D(또는 '출발하자' · 문 열렸다 닫힘 — 연결 뒤) → 쉼표 끝, 남은 거리 한 줄

## 3. 언제 켜지나

| 트리거 | 조건 | 비고 |
|---|---|---|
| 쉬어 갈까요 제안 | **연속 주행 2시간** 넘음(+30분마다 다시 — 도로교통공단 '2시간마다 15분 휴식') · 다음 휴게소가 3~20km 앞 | 지금 `DriveCareFeature`의 `long_drive` 이벤트를 쉼표가 받아 휴게소 거리와 묶는다 · 휴게소가 없으면 "다음 휴게소에서 쉬어 가요"만 |
| 앞당김 | **야간(0~6시)** 또는 졸음 신호(하품 소리·긴 무응답 🔍)면 **90분**부터 | 앱 시계 · 졸음 신호는 미시험 — 시연은 야간 시각 주입 |
| 운전자 말 | "쉬고 싶어" · "졸려" · "휴게소 어디야" | 졸림은 바로 P1 제안 |
| 쉼표 시작 | 제안을 받아들인 뒤 휴게소에서 기어 P(속도 0) · 또는 정차 중 "쉼표 시작" | |
| 쉼표 끝 | **15분 고정**("5분 더"는 한 번에 5분씩 늘림) · 기어 D · "출발하자" · 문 열림→닫힘(Claude가 연결) | |

## 4. 현비서가 하는 말 (예시 · 우선순위)

| 상황 | 말 | 단계 |
|---|---|---|
| 제안 | "두 시간째 달리고 있어요. 12킬로미터 앞 기흥휴게소에서 15분 쉬어 갈까요?" | P1(주행 필수 — 쿨다운에 안 묶이게 `Speaker.eventPrio`에 고정) |
| 거절 | "알겠어요, 30분 뒤에 다시 여쭤볼게요." | 대답 |
| 쉼표 시작 | "15분 쉼표 시작할게요. 창문 조금 열고 숨 크게 세 번 쉬어 봐요." | P2 |
| 깨우기 | "3분 남았어요" → "가볍게 기지개 켜 볼까요" → "출발 준비됐어요?" | P2 |
| 늘리기 | ("5분 더") "네, 5분 더 쉬어요." | 대답 |
| 끝 | "강남역까지 1시간 10분 남았어요. 천천히 출발해요." | P2 |

- 말 금지: '졸음을 감지했어요'(카메라 없음) · 시트·조명을 '바꿨어요'(제어 승인 전 — "시트를 조금 눕혀 보세요"처럼 안내만)

## 6. 앱 기능 — `feature/RestFeature.kt`

- `tick`: 연속 주행·다음 휴게소 거리로 제안 판정 · 쉼표 타이머 · 깨우기 단계 · 기어 D면 끝
- `onHeard`: "쉬고 싶어"·"쉼표 시작"·"출발하자"·"5분 더"(앱이 바로) · `onReply`: 두뇌 답 `rest` 필드
- `render`: 쉼표 판 값(남은 시간 · 단계 · 휴게소 이름) — 그리기는 그리기 훅(예정)으로 오른쪽 정보창 판
- `fallback`: `rest_offer`·`rest_wake` 규칙 문장 · 등록: `Registry`에 `DriveCareFeature` 앞(긴 주행 이벤트를 먼저 받게)
- 시연 인텐트(예정): `--ei longmin 1`(있음 — 제안 기준을 줄임) · `--ei restsec 60`(쉼표 길이 줄이기) · `--es clock 02:30`(야간 앞당김 시험)
- 문 열림: `drive/Sense` 또는 쉼표 안에서 Vehicle 문 상태 구독(권한 추가 · 실패하면 기어만으로 끝냄)

## 7. 서버 기능 모듈 — `server/hyun/features/rest.py`

- `RULES`: 쉼표 제안은 연속 시간·휴게소 거리·취향(커피·간식)으로 두 문장 · '졸음 감지' 표현 금지 · 시트·조명은 '바꿨어요' 금지(안내만) · 거절하면 다시 권하지 않음(30분 뒤 앱이 다시 부름) · 졸음쉼터는 말하지 않음(자료 없음)
- `SCHEMA`: `rest: "start" | "skip" | ""`(운전자 수락/거절)
- `block`: `[쉼표]` 연속 주행 분 · 다음 휴게소 이름·거리 · 쉼표 중이면 남은 분
- `post`: 쉼표 기록(시작·끝·장소) → `data/rest.jsonl`(git 제외) — 사업성 '휴게 기록' 근거

## 8. 주행 규칙

- 주행 중: 제안 한 줄 + 음성만(1칸 = 내비 판 바로 아래 한 줄 · 반반 = 길 카드 아래) · 타이머·카드 없음 · 회전 300m 앞이면 기다렸다 말함
- 정차(쉼표 중): 타이머·숨 고르기·휴게소 카드를 오른쪽 정보창 전체에 · 터치는 '출발'·'5분 더' 두 개

```json
{
  "id": "e11",
  "title": "쉼표 — 오래 달리면 휴게소에서 15분 쉬어 가기",
  "situation": "고속도로 2시간째 주행 · 12km 앞 기흥휴게소 (시연: 제안 기준을 1분으로 줄임)",
  "why": "연속 주행 시간과 경로의 다음 휴게소를 묶어 먼저 쉬어 가자고 하고, 휴게소에서 15분 쉼표를 지켜 준다",
  "steps": [
    {"do": "intent", "extras": "--ei longmin 1 --es restarea '기흥휴게소|12000'"},
    {"do": "vc", "args": ["gear", "Drive"]}, {"do": "vc", "args": ["speed", "90"]},
    {"wait": "log", "pattern": "event\\|rest_offer", "timeout": 90},
    {"wait": "tts"},
    {"do": "say", "text": "응 쉬어 갈래", "voice": false},
    {"do": "vc", "args": ["speed", "0"]}, {"do": "vc", "args": ["gear", "Park"]},
    {"wait": "log", "pattern": "rest\\|start", "timeout": 20},
    {"wait": "sec", "sec": 3},
    {"shot": "쉼표 화면 — 타이머 · 숨 고르기 · 휴게소 카드"},
    {"do": "vc", "args": ["gear", "Drive"]},
    {"wait": "log", "pattern": "rest\\|end", "timeout": 20}
  ],
  "expect": [
    {"log": "event\\|rest_offer", "what": "연속 주행 + 휴게소 거리로 제안"},
    {"log": "say\\|P1\\|.*쉬어", "what": "P1로 쉬어 가자고 말함"},
    {"log": "rest\\|start", "what": "정차하자 쉼표 시작"},
```

## 10. 결정 (11-08 · Claude 권고 — 사용자 위임, 바꿀 수 있음)

| 질문 | 결정 | 이유 |
|---|---|---|
| 제안 기준 | **연속 2시간**(+30분마다 다시) · 야간(0~6시)이나 졸음 신호면 **90분**으로 앞당김 | 도로교통공단 권고('2시간마다 15분 휴식')를 따르면 근거를 대기 쉽고, 위험한 때만 당긴다 |
| 쉼표 길이 | **15분 고정** · "5분 더"로만 늘림 | 권고 시간과 같게 · 줄이는 말은 받지 않아 쉼표가 짧아지지 않게 |
| 졸음쉼터 추천 | **11-15 뒤**(MVP는 경로상 휴게소 TBT만) | 위치 자료에 공공데이터 키가 필요 — 휴게소 TBT는 실측됨 |
| 시트·조명 제어 | MVP는 **안내 문장만** · 제어는 기획서 '발전 가능성' | Vehicle Control 승인 전엔 약속하지 않는다(절대 원칙: 실차에서 되는 것만) |
| 문 열림 | **Claude가 현비서에 연결**(권한 추가 + 프로브) | SDK 실측 OK · 쉼표 끝·오늘 할 일 하차 확인에 같이 쓴다 |
