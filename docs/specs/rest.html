쉼표 rest — 화면 구성도결정 반영 — 구현 대기

오래 달리면 경로의 다음 휴게소에서 쉬어 가자고 하고, 휴게소에서 15분 쉼표(타이머·숨 고르기·깨우기)를 지켜 준다

짝 문서: 기능 명세 rest.md

회색 점선 = 지금 있는 요소 · 색 테두리 + 번호 = 이 모듈이 새로 넣는 요소(같은 번호 = 같은 요소) · 실제 비율(1칸 1706×1210 · 반반 841×1210 앱 영역, 화면엔 36%로 줄임) · 오른쪽 정보창의 새 판은 '그리기 훅'(예정) 자리

번호별 설명

  1. 쉼표 판 — 남은 시간 큰 숫자(12:40) · 숨 고르기 원 · 깨우기 3단계 점(3분 전 → 기지개 → 출발 준비)
  2. 휴게소 소개 카드 — 사진 · 대표 메뉴 · 취향 추천(지금 있는 소개 카드 재사용)
  3. 정차 버튼 두 개 — [출발] [5분 더] (터치는 정차 중에만)
  4. 주행 중 한 줄 띠 — '연속 2시간째 · 12km 앞 기흥휴게소' + 음성 제안(P1). 그림·타이머 없음

주행 규칙

주행 중엔 한 줄 + 음성만(회전 300m 앞이면 기다렸다 말함). 타이머·카드·버튼은 정차(쉼표 중)에만.
