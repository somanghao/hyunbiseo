## 1. 목적 · 심사 4축

시동을 걸면 오늘 할 일을 보여 주고, **장소가 있는 일은 "가는 길에 들를까요?" → 내비 경유지**로 넣어 준다. 들렀다 나오면 "다녀왔어요?"로 완료까지.

- 차량특화성: 할 일 목록이 아니라 '지금 이 길'에 붙는다 — 경유지 추가·경유지 도착·하차(문) 확인은 차에서만
- 창의성: 할 일 → 장소 찾기 → 경유지 → 완료 확인까지 말 몇 마디로
- 기술활용성: NaviHelper `addWaypoint`(실측)·`onWayPointArrived` · 카카오 로컬 키워드 검색(키 받음·실측 11-08) · 서버 `tasks.json`(폰과 같은 목록)
- 사업성: 폰(짭비서) ↔ 차(현비서) 같은 할 일 목록 · 장소 제휴(세탁소·약국·마트 픽업)

## 2. 11-15 MVP 시연 장면

1. (전날 폰에서) "내일 세탁소 들르기 추가해 줘" — 또는 차에서 "현비서야 세탁소 들르기 추가해 줘"
2. 시동 → **시동 카드** "오늘 할 일 2 · 세탁소 들르기 · 19시 회의 자료" + "세탁소, 가는 길에 들를까요?"
3. "응" → 카카오 로컬로 경로 근처 세탁소 1곳(서버 `places.py` 실시간 호출 — 도착 추천과 같은 어댑터) → `addWaypoint` → 길 카드에 "세탁소 거쳐 1.2km"
4. 경유지 도착(시연: `--es event waypoint` — 에뮬 GPS가 안 움직임) → 정차 → "다녀왔어요? 세탁소 완료할까요?" → "응" → 완료
5. 정차 화면 "할 일 1/2 완료"

## 3. 언제 켜지나

| 트리거 | 조건 |

| 가는 길에 들르기 제안 | 장소가 있는 할 일 하나만(MVP) · 목적지가 정해진 뒤 · 지역 검색 결과가 경로 근처 |

## 6. 앱 기능 — `feature/TodayFeature.kt`

- `start`·`tick`: 시동 때 `/hyun/tasks` 받기 · 경유지 도착 + 정차면 완료 확인
- `onHeard`: "할 일 뭐 있어?"(앱이 바로 읽기) · `onReply`: 두뇌 답 `todo`·`done`·`via`(기존 RouteFeature `addVia` 재사용)
- `render`: 시동 카드 · 정차 목록(완료 체크 — 터치는 정차만) · 주행 중 길 카드 경유지 줄(이미 있음)
- 짭비서 `PhoneFeature`의 할 일 코드와 겹치는 부분은 공용으로

## 7. 서버 기능 모듈 — `server/hyun/features/today.py` (+ 장소 = `places.py`, 도착 추천과 공유)

- `phone.py`의 `tasks.json`·`/hyun/tasks` 그대로 쓰고, 차에서 쓰는 규칙만 더함
- `RULES`: 할 일에 장소가 있으면 '가는 길에 들를까요?' 한 번만 · 목적지가 그 장소면 묻지 않음
- `SCHEMA`: 기존 `todo`·`done` + `place_query: "세탁소" | ""`(장소 찾기 요청)
- `block`: `[오늘 할 일]` 남은 할 일 3 · 장소 있는 것 표시
- 장소 찾기 = `places.py`(도착 추천과 같은 어댑터) — 카카오 키워드 검색(경로 근처 반경 · 실시간 호출만, 결과는 파일에 저장 안 함) → 이름·좌표 → 앱 `via`
- 예비(키·네트워크 실패): 할 일에 장소 좌표를 미리 적어 둔 시연용 항목(`tasks.json`의 `place`)
- 여러 곳 순서 짜기(가는 김에 원안 — 할 일 여러 개를 경로에 최적 순서로)는 11-15 뒤

## 8. 주행 규칙

- 주행 중: 시동 카드·목록 없음 · 경유지는 길 카드 한 줄 · 리마인더는 말 + 한 줄
- 정차: 시동 카드(최대 3) · 목록 · 완료 체크(터치)
