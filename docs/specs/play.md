## 1. 목적 · 심사 4축

동승자(아이·친구)와 **말로 하는 놀이** — 끝말잇기와 퀴즈. 차가 문제를 던지고 음성으로 답을 알아듣는다. 내비가 말하거나 회전 앞이면 저절로 잠깐 멈춘다.

- 차량특화성: 회전 300m 앞·내비 안내 때 자동 멈춤 · 동승자 좌석이 차면 먼저 제안 · **지나는 길 퀴즈**(지금 지나는 동네·도로·휴게소로 문제)
- 창의성: 경로가 곧 문제집 — "지금 지나는 판교는 어떤 회사들이 많을까요?"
- 기술활용성: 앱 귀(호출어 없이 놀이 중엔 바로 듣기 · Whisper 받아 적기) · 앱 판정(끝말잇기 — 두뇌를 안 기다려 즉답) · 두뇌(퀴즈 내기·느슨한 정답 판정) · 내비 위치·TBT
- 사업성: 가족 이동 시간 콘텐츠 · 교육 퀴즈 제휴(어린이 학습) · 지역 관광 퀴즈(지자체)

## 2. 11-15 MVP 시연 장면

1. 정차 또는 주행 중 "현비서야 끝말잇기 하자" → "좋아요, 제가 먼저 할게요. 기차!"
2. 동승자 "차표" → 앱 판정 OK → 현비서 즉답 "표범!" (몇 턴 · 두음법칙 '녀→여' 허용 · 반복 금지 · 없는 말이면 "그런 말은 사전에 없어요, 다시!")
3. 회전 300m 앞(시연 `--ei turnm 250`) → "잠깐, 우회전하고 이어서 할게요" → 지나면 이어서
4. "이제 퀴즈 내 줘" → "지나는 길 퀴즈! 지금 지나는 판교에는 어떤 회사들이 많을까요? 힌트, 게임이랑 인터넷" → "게임 회사!" → "정답!" (난이도 기본 '쉬움' — "어렵게 해 줘"면 '보통')
5. 정차 → 오늘 놀이 기록(끝말잇기 9턴 · 퀴즈 3문제 중 2개)

## 3. 언제 켜지나

| 트리거 | 조건 |
|---|---|
| 시작 | "끝말잇기 하자" · "퀴즈 내 줘"(지나는 길 퀴즈 · "상식 퀴즈") · (동승자 좌석이 차고 30분 넘게 조용하면 P3로 먼저 제안 — 좌석 연결 뒤) |
| 난이도 | 기본 **쉬움**(동승 아이 기준) · "어렵게 해 줘" → **보통** · "쉽게 해 줘" → 쉬움 — 두 단계만 |

| 잠깐 멈춤 | 회전 300m 안 · 내비 음성 · 경로 정찰 P0 · 운전자 "잠깐" |
| 끝 | "그만" · "조용히" · 20초 대답 없음 · 도착 |

## 6. 앱 기능 — `feature/PlayFeature.kt` + `assets/words-ko.txt`

- `onHeard`: 놀이 중엔 말을 먼저 가로챔 — 끝말잇기 판정(끝 글자 · 두음법칙 · 단어장 · 반복 금지)과 차 차례 단어를 **앱이 즉시**(두뇌 0초) · 퀴즈 답은 두뇌로
- `tick`: 회전 게이트·P0면 멈춤 표시 · 20초 무응답 끝 · `render`: 주행 = 한 줄(지금 단어·턴) / 정차 = 놀이 기록
- 단어장 `words-ko.txt` = **우리가 직접 만드는 일반 명사 목록**(아이가 아는 말 위주 몇천 개 — 단어 자체는 저작물이 아님, 사전 원문·뜻풀이는 복사하지 않음) · 쉬움 = 두세 글자 · 보통 = 더 긴 말·두음법칙
- 기존 `Hyun`의 대화 창을 놀이 동안 열어 둠(`listenAfter`)

## 7. 서버 기능 모듈 — `server/hyun/features/play.py`

- `RULES`: 퀴즈는 한 번에 한 문제 · 힌트 하나 · 느슨한 정답 판정(뜻이 맞으면 정답 — 앱이 받아 적은 말을 정답 후보와 비교해 보조) · **지나는 길 퀴즈**는 [위치] 블록의 동네·도로·다음 휴게소로 · **상식 퀴즈**는 아이 눈높이 · 난이도 쉬움/보통 · 확실하지 않은 사실은 문제로 내지 않음 · 온기 포인트 얘기 금지
- `SCHEMA`: `play: {game: "quiz"|"wordchain"|"", kind: "road"|"general"|"", level: "easy"|"normal", q: "", answer: "", verdict: "correct"|"wrong"|"", score: n}` — `answer`는 앱 판정 보조용(화면엔 안 띄움)
- `block`: `[놀이]` 진행 중 게임 · 지금 문제 · 맞힌 수
- 퀴즈 출처: 두뇌가 만든 문제(지나는 길 · 상식) + (MVP 안정용) 문제 은행 `assets/quiz.json` 30문제(상식 쉬움 20 · 보통 10)
- 동요 노래방은 **11-15 뒤**(소리·저작권·오디오 포커스 시험이 필요)

## 8. 주행 규칙

- 주행 중: **게임 화면 없음** — 한 줄(“끝말잇기 · 차 차례 '표범' · 9턴”) + 소리만 · 터치 없음 · 회전 앞·내비 음성이면 멈춤
- 정차: 놀이 기록 카드(오늘 턴·맞힌 문제) — 단어 목록도 정차 때만
- 운전자가 "조용히"면 즉시 끝

## 10. 결정 (11-08 · Claude 권고 — 사용자 위임, 바꿀 수 있음)

| 질문 | 결정 | 이유 |
|---|---|---|
| 동요 노래방 | **11-15 뒤** | 사용자 목록(끝말잇기 · 퀴즈)에 없음 · 노래 저작권·오디오 포커스 미시험 |
| 퀴즈 종류 | **지나는 길 퀴즈**(동네·도로·휴게소 — 두뇌가 문제, 앱이 정답 판정 보조) + **상식 퀴즈** · 넌센스·초성은 나중 | 지나는 길 퀴즈가 차량특화성 · 상식은 안정용(문제 은행 30) |
| 난이도 | 동승 아이 기준 **쉬움/보통 두 단계**("어렵게 해 줘" · "쉽게 해 줘") | 단계가 많으면 말로 고르기 어렵다 |
| 단어장 | **우리가 직접 만드는 일반 명사 목록** — 사전 원문·뜻풀이는 복사하지 않음 | 단어 자체는 저작물이 아님 · 라이선스 걱정 없이 아이 말 위주로 |
| 온기 포인트 | **주지 않음** | 온기 = 안전운전 보상만 — 섞으면 포인트 뜻이 흐려진다 |
| 아이 목소리 인식 | **사람이 시험** — 사용자 실음성 시험 목록에 추가(아이 목소리로 끝말잇기 5턴) | 녹음 주입(SAPI 어른 목소리)으론 아이 발음을 볼 수 없다 |
