짝 문서: 기능 명세 play.md

회색 점선 = 지금 있는 요소 · 색 테두리 + 번호 = 이 모듈이 새로 넣는 요소(같은 번호 = 같은 요소) · 실제 비율(1칸 1706×1210 · 반반 841×1210 앱 영역, 화면엔 36%로 줄임) · 오른쪽 정보창의 새 판은 '그리기 훅'(예정) 자리

번호별 설명

  1. 놀이 기록 카드(정차) — 끝말잇기 9턴(기차 → 차표 → 표범 …) · 퀴즈 2/3
  2. 지금 문제(정차) — '판교에는 어떤 회사가 많을까요? 힌트: 게임·인터넷'
  3. 주행 한 줄 — '🎲 끝말잇기 · 차 차례 표범 · 9턴' (게임 화면 없음 · 소리 놀이)
  4. 잠깐 멈춤 표시 — 회전 300m 앞 · 내비 음성 · 위험 때 '잠깐 멈춤' (지금 있는 알림 자리)

주행 규칙

주행 중엔 게임 화면 없음 — 한 줄 + 소리만 · 터치 없음 · 회전 앞·내비 음성이면 멈춤 · '조용히'면 즉시 끝. 기록·문제 글은 정차에만.
