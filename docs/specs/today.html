짝 문서: 기능 명세 today.md

회색 점선 = 지금 있는 요소 · 색 테두리 + 번호 = 이 모듈이 새로 넣는 요소(같은 번호 = 같은 요소) · 실제 비율(1칸 1706×1210 · 반반 841×1210 앱 영역, 화면엔 36%로 줄임) · 오른쪽 정보창의 새 판은 '그리기 훅'(예정) 자리

번호별 설명

  1. 시동 카드 — 오늘 할 일(최대 3) · 장소 있는 일엔 '가는 길에' 표시
  2. 가는 길에 들르기 — 경로 근처 장소 1곳(카카오 로컬 실시간 검색) · [넣기] (말로 '응'도 됨)
  3. 경유지 줄 — 길 카드·내비 판의 '세탁소 거쳐 1.2km'(지금 있는 경유지 표시를 씀)
  4. 다녀왔어요? — 경유지 도착 + 정차 때 완료 확인 · 할 일 1/2 완료

주행 규칙

주행 중엔 경유지 한 줄(이미 있는 길 표시)과 말만 · 리마인더는 말 + 한 줄. 시동 카드·목록·완료 체크(터치)는 정차에만.
