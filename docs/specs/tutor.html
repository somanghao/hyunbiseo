초보가 어려워하는 길(고속도로 진입·좌회전·터널·요금소·회전교차로·사고)이 오기 직전에 그림 + 한 문장, 정차하면 큰 그림으로 다시

짝 문서: 기능 명세 tutor.md

회색 점선 = 지금 있는 요소 · 색 테두리 + 번호 = 이 모듈이 새로 넣는 요소(같은 번호 = 같은 요소) · 실제 비율(1칸 1706×1210 · 반반 841×1210 앱 영역, 화면엔 36%로 줄임) · 오른쪽 정보창의 새 판은 '그리기 훅'(예정) 자리

번호별 설명

  1. 큰 그림 카드(정차) — 진입 차로·가속 차로·합류 화살표 그림
  2. 설명 3줄(정차) — ① 깜빡이 먼저 ② 가속 차로에서 속도 맞추기 ③ 옆 차 보고 합류
  3. 칩(정차) — [다음 팁] [그만]
  4. 초보 모드 배지 — 켜져 있을 때만 이름 옆에(‘그만’ 한마디로 끔)
  5. 한눈 그림 카드(주행) — 그림 하나 + 6자 안 글('깜빡이 먼저') 6초 · 1칸은 내비 판 바로 아래 / 반반은 길 카드 아래 · 터치 없음 · 음성 한 문장과 같이

주행 규칙

주행 중엔 한눈 그림 카드 하나(6초) + 음성 한 문장 · 터치 없음 · 회전 300m 안에선 새 카드·말 없음. 큰 그림·설명·칩은 정차에만.
